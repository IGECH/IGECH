# 🚀 Sobre nosotros

IGECH S.A. es una empresa especializada en **Contact Center**, cobranzas y soluciones corporativas con presencia en distintas provincias del nordeste argentino.

Actualmente impulsamos una nueva área de **IT & Desarrollo** enfocada en:

- Modernización de procesos internos.
- Automatización operativa.
- Integración de plataformas corporativas.
- Desarrollo de soluciones tecnológicas escalables.
- Implementación de herramientas basadas en IA.
